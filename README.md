Pour lancer le projet merci de:
1. Cloner la branche sur la quelle le projet est commité et poussé. 
(git clone --branch CC_Reseau_Social --single-branch https://github.com/Adamsad97/Projets_Symfony.git)

2. Installer le composer après le clonage du projet
3. Vous pouvez vous créer un compte pour vous connecter en tant que USER;
4. Pour vous connecter en tant qu'Admin, voici les identifiants de connexion.
Email: admin@example.com
Mot de passe: 1234

5. Pour créer votre compte, votre mot de passe doit avoir au minimum 4 caractères, et au maximum 30 caractères
6. Vous ne pouvez pas vous inscrire plus d'une fois avec la même adresse email.
7. Pour vous connecter, cliquez sur l'icone profil en haut à droit, il vous dirigera sur la page de connexion, si vous avez déjà un compte. Sinon, vous en créeé un en cliquant sur le lien bleu "Créer un compte".
8. En tant qu'Admn, vous ne pouvez pas tout modifiez. Vous pouvez modifiez le nom et le prénom d'un utilisateur. Vous ne pouvez toutefois modifiez ses identifiants de connexion (email et mot de passe).
